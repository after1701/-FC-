# RED DEVIL SQUAD LAB v2

호날두 맨유 시절을 테마로 한 FC Online 스쿼드 메이커 프로토타입입니다.

## 실행 방법
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

## 포함 기능
- 4-3-3, 4-2-3-1, 4-1-2-1-2, 4-4-2, 3-5-2 포메이션
- 선수 배치, 드래그 이동, 교체, 삭제
- 스쿼드 저장/불러오기/JSON 내보내기
- 선수 상세 조회 및 강화 단계 선택 UI
- 포지션 공백/최저 OVR 기반 추천, 예산/전술 성향 필터
- 팀컬러 후보 인원 집계
- Nexon Data Center의 비공식·비문서화 PlayerList / PlayerAbility 경로에 서버 측 요청 시도
- 선수 이미지 CDN URL 연결 시도

## 중요한 한계
- 넥슨 API 키 없이 데이터센터의 비공식 웹 경로를 호출합니다. 넥슨 측에서 요청을 차단하거나 HTML 구조를 바꾸면 실시간 검색/상세 조회가 실패할 수 있습니다.
- 데이터센터 검색 HTML 파싱은 현재 환경에서 외부 서버에 직접 접속해 검증하지 못했습니다. 따라서 실제 넥슨 응답과 호환된다고 보장하지 않습니다.
- 선수 추천은 규칙 기반이며, 완전한 최적화나 게임 내 AI 추천과 같지 않습니다.
- 강화 단계 선택 UI는 포함했지만, 실제 강화별 OVR/세부 능력치 상승 공식은 구현했다고 주장하지 않습니다.
- 팀컬러는 상세 조회에서 반환되는 후보 명칭과 현재 인원만 집계합니다. 실제 발동 조건/능력치 보너스/중복 규칙은 별도 검증이 필요합니다.
- 시장 가격은 API 키 없이 신뢰 가능한 실시간 가격 데이터로 확보하지 못하므로 가격을 임의로 표시하지 않습니다.
- 배경은 호날두 맨유 시절의 붉은 유니폼과 경기장 분위기를 참고해 생성한 오리지널 이미지이며, 실제 선수 사진이나 FC Online 공식 스크린샷이 아닙니다.
